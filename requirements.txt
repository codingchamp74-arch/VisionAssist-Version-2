#   mediapipe              py3-none-win_amd64  (pure C DLL + ctypes)

#   numpy / Pillow         cp314
#
# mediapipe must be >= 1.0.0: the 0.10.x releases only shipped cp38-cp312
# wheels and will not install on Python 3.13 / 3.14.
