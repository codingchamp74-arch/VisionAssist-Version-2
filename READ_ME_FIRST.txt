VISIONASSIST  —  how to run this project
========================================

This is a PYTHON desktop app.  You do NOT need Node.js or npm.
Works with Python 3.9, 3.10, 3.11, 3.12, 3.13 and 3.14.


1. Install Python from  https://www.python.org/downloads/
   On the first installer screen tick:   Add python.exe to PATH

2. Open THIS folder in VS Code  (the folder that contains main.py)

3. Open the terminal  (Ctrl + `)  and run:

      python -m pip install -r requirements.txt
      python main.py

   Or double-click  RUN.bat


The gestures control YOUR apps - Spotify, VLC, your browser - plus
system volume and window management.  Nothing is played internally.

Full walkthrough and troubleshooting:  HOW_TO_RUN.md
